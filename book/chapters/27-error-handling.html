4.7 Обработка ошибок

Ключевые слова

обработка ошибок Python, исключения Python, try except Python, ValueError Python, ZeroDivisionError Python, finally Python, raise Python

Важное уведомление

Главный вопрос главы:

Как сделать так, чтобы программа могла обработать ожидаемую ошибку и продолжить работу?

Представим программу, которая получает возраст пользователя:

age = int(input("Введите возраст: "))

print("Ваш возраст:", age)

Если пользователь введёт:

25

программа выполнится успешно.

Но что произойдёт, если ввести:

двадцать пять

Python не сможет преобразовать эту строку в число.

Возникнет исключение:

ValueError

Если исключение не обработано, выполнение программы прервётся.

Python позволяет заранее определить, что делать в подобных ситуациях.

Для этого используются try и except.

Ошибки и исключения

Не все ошибки одинаковы.

Рассмотрим два случая.

Синтаксическая ошибка:

if age >= 18
    print("Доступ разрешён")

Здесь пропущено двоеточие.

Python обнаружит SyntaxError ещё до выполнения программы.

Исключение во время выполнения:

number = int("hello")

Синтаксис правильный, но преобразовать "hello" в целое число невозможно.

Возникнет:

ValueError

Именно с такими исключениями мы будем работать в этой главе.

УведомлениеВажно

try и except не предназначены для исправления неправильного синтаксиса программы.

Они позволяют обрабатывать исключения, возникающие при выполнении кода.

Знакомые исключения Python

Мы уже встречали ситуации, в которых Python сообщает об ошибке.

Исключение Причина
ValueError Значение не подходит для операции
ZeroDivisionError Деление на ноль
TypeError Операция с неподходящими типами
KeyError Отсутствующий ключ словаря
IndexError Индекс за пределами последовательности

Например:

numbers = [10, 20, 30]

print(numbers[5])

Результат:

IndexError: list index out of range

Или:

user = {"name": "Анна"}

print(user["email"])

Возникнет KeyError.

Необработанное исключение прерывает обычный ход выполнения программы.

Первая обработка ошибки: try и except

Рассмотрим пример:

try:
    age = int(input("Введите возраст: "))
    print("Ваш возраст:", age)

except ValueError:
    print("Ошибка: введите целое число")

Здесь:

try:

обозначает блок, в котором может возникнуть исключение.

А:

except ValueError:

указывает, какое исключение мы готовы обработать.

Если пользователь введёт:

abc

программа выведет:

Ошибка: введите целое число

Вместо необработанного исключения пользователь получит понятное сообщение.

Как работает try/except

Общая форма:

try:
    # Код, который может вызвать исключение

except ValueError:
    # Действия при ValueError

Порядок выполнения:

Начало try
    |
    v
Выполнение кода
    |
    +-- Ошибки нет --> продолжение программы
    |
    +-- ValueError --> блок except ValueError

Посмотрим на пример без пользовательского ввода:

try:
    number = int("42")
    print("Число:", number)

except ValueError:
    print("Не удалось получить число")

print("Программа завершена")

Результат:

Число: 42
Программа завершена

Блок except не выполняется, потому что исключение не возникло.

СоветЧто стоит попробовать

Замените:

int("42")

на:

int("Python")

И сравните результат.

Это простой способ увидеть оба сценария работы try/except.

Что происходит после исключения

Если исключение возникло внутри try, оставшиеся инструкции этого блока пропускаются.

try:
    number = int("abc")

    print("Число:", number)

except ValueError:
    print("Неверный формат числа")

print("Работа продолжается")

Результат:

Неверный формат числа
Работа продолжается

Строка:

print("Число:", number)

не выполняется.

После обработки исключения программа переходит к коду после конструкции try/except.

Обработка деления на ноль

Ещё один распространённый случай:

a = 100
b = 0

try:
    result = a / b
    print(result)

except ZeroDivisionError:
    print("На ноль делить нельзя")

Результат:

На ноль делить нельзя

Измените:

b = 0

на:

b = 5

Теперь результатом будет:

20.0

Мы обрабатываем только конкретную ожидаемую проблему — деление на ноль.

Несколько блоков except

Одна операция может приводить к разным исключениям.

Например, программа получает два числа от пользователя:

try:
    a = int(input("Первое число: "))
    b = int(input("Второе число: "))

    result = a / b

    print("Результат:", result)

except ValueError:
    print("Нужно вводить целые числа")

except ZeroDivisionError:
    print("Делитель не может быть равен нулю")

Возможны три сценария.

Ввод Результат
10 и 2 5.0
abc и 2 Сообщение о неверном числе
10 и 0 Сообщение о делении на ноль

Каждый except отвечает за свой тип исключения.

Это позволяет показывать пользователю более точные сообщения.

Получение текста ошибки через as

Иногда полезно узнать подробности возникшего исключения.

Для этого используется as:

try:
    number = int("Python")

except ValueError as error:
    print("Ошибка:", error)

Переменная:

error

содержит объект исключения.

При выводе Python показывает его текстовое представление.

Это удобно при отладке, когда нужно понять причину ошибки.

Обработка нескольких типов одним except

Если действия для нескольких исключений одинаковые, их можно объединить:

try:
    value = int("abc")
    result = 100 / value

except (ValueError, ZeroDivisionError):
    print("Не удалось выполнить вычисление")

Здесь один блок обрабатывает два типа исключений.

Но если пользователю нужны разные сообщения, лучше использовать отдельные except.

Блок else

Иногда после успешного выполнения try нужно выполнить дополнительный код.

Для этого существует else:

try:
    number = int("25")

except ValueError:
    print("Неверное число")

else:
    print("Преобразование успешно")
    print("Результат:", number)

Результат:

Преобразование успешно
Результат: 25

else выполняется, только если блок try завершился без исключения.

Это позволяет отделить потенциально опасную операцию от дальнейшей обработки результата.

Блок finally

Блок finally предназначен для действий, которые нужно выполнить при завершении конструкции try.

try:
    number = int("abc")

except ValueError:
    print("Ошибка преобразования")

finally:
    print("Проверка завершена")

Результат:

Ошибка преобразования
Проверка завершена

Если заменить "abc" на "42", finally тоже выполнится.

finally часто используют для освобождения ресурсов, например закрытия открытых соединений.

В этой главе достаточно понимать его основное назначение.

УведомлениеОсобенность finally

Блок finally выполняется и при успешном завершении try, и при возникновении исключения, в том числе необработанного.

При этом finally не означает, что исключение автоматически обработано.

Полная конструкция try/except/else/finally

Все части можно использовать вместе:

try:
    number = int("20")
    result = 100 / number

except ValueError:
    print("Неверный формат числа")

except ZeroDivisionError:
    print("Деление на ноль")

else:
    print("Результат:", result)

finally:
    print("Вычисление завершено")

Результат:

Результат: 5.0
Вычисление завершено

Необязательно использовать все блоки одновременно.

Чаще всего достаточно:

try:
    ...

except ValueError:
    ...

Дополнительные блоки нужны, когда у них есть конкретное назначение.

Самостоятельное создание исключения: raise

До сих пор исключения возникали автоматически.

Но иногда программа должна сама отклонить некорректные данные.

Например, количество товара не может быть отрицательным.

quantity = -5

if quantity < 0:
    raise ValueError("Количество не может быть отрицательным")

Здесь:

raise

создаёт исключение.

А:

ValueError(...)

описывает проблему.

Если исключение не обработано, выполнение программы прервётся.

raise вместе с try/except

Созданное нами исключение можно обработать:

try:
    quantity = -5

    if quantity < 0:
        raise ValueError("Количество не может быть отрицательным")

    print("Количество:", quantity)

except ValueError as error:
    print("Ошибка:", error)

Результат:

Ошибка: Количество не может быть отрицательным

Здесь важно различать две операции:

raise

создаёт исключение.

except

обрабатывает подходящее исключение.

Пример: проверка суммы перевода

Рассмотрим небольшую программу:

balance = 5000

try:
    amount = int(input("Сумма перевода: "))

    if amount <= 0:
        raise ValueError("Сумма должна быть положительной")

    if amount > balance:
        raise ValueError("Недостаточно средств")

except ValueError as error:
    print("Перевод отклонён:", error)

else:
    balance -= amount

    print("Перевод выполнен")
    print("Остаток:", balance)

Программа проверяет:

  1. Можно ли преобразовать ввод в число.
  2. Положительная ли сумма.
  3. Достаточно ли средств.

Изменение баланса происходит только после успешной проверки.

Это пример того, как обработка исключений помогает управлять выполнением программы.

Почему не стоит использовать except без типа

В Python существует запись:

try:
    number = int("abc")

except:
    print("Произошла ошибка")

Она перехватывает слишком широкий круг исключений.

Из-за этого можно случайно скрыть проблему, которую программа не умеет правильно обрабатывать.

В учебных примерах лучше указывать конкретный тип:

except ValueError:

или:

except ZeroDivisionError:
ПредупреждениеНе скрывайте ошибки

Не используйте без необходимости:

except:
    pass

Такая конструкция может скрыть важную проблему, оставив программу в неожиданном состоянии.

Обрабатывайте только те исключения, для которых действительно предусмотрено разумное действие.

Когда try/except не нужен

Не каждую ситуацию нужно превращать в исключение.

Например, проверить наличие ключа словаря можно через:

user = {"name": "Анна"}

email = user.get("email", "Не указан")

Это нормальный способ работы с необязательным полем.

Аналогично, если можно заранее проверить условие, иногда проще использовать if:

divisor = 0

if divisor != 0:
    print(100 / divisor)
else:
    print("Деление невозможно")

Выбор зависит от ситуации.

if проверяет ожидаемое условие.

try/except позволяет обработать исключение, которое возникло при выполнении операции.

Типичные ошибки начинающих

Слишком большой блок try

Не стоит помещать внутрь try всю программу.

Лучше ограничивать его операциями, которые действительно могут вызвать ожидаемые исключения.

Неправильный тип исключения

Например:

try:
    number = int("abc")

except ZeroDivisionError:
    print("Ошибка")

Такой обработчик не поможет, потому что возникает ValueError.

Использование переменной после неудачного преобразования

try:
    number = int("abc")

except ValueError:
    print("Ошибка")

print(number)

Если преобразование не удалось, переменная number не получила значение.

Последняя строка приведёт к новой ошибке.

Правильнее выполнять действия с результатом в else:

try:
    number = int("abc")

except ValueError:
    print("Ошибка")

else:
    print(number)

Что важно запомнить

Базовая обработка:

try:
    ...

except ValueError:
    ...

Несколько исключений:

except ValueError:
    ...

except ZeroDivisionError:
    ...

Получение сообщения:

except ValueError as error:
    print(error)

Действие при успешном выполнении:

else:
    ...

Завершающее действие:

finally:
    ...

Самостоятельное создание исключения:

raise ValueError("Некорректное значение")

Главный принцип:

Не пытайтесь скрыть любую ошибку. Обрабатывайте ожидаемые проблемы и оставляйте остальные видимыми для исправления.

Практические задания

Задание 1. Номер этажа

Сложность: начальная

Пользователь вводит номер этажа.

Преобразуйте введённое значение в целое число.

Если пользователь введёт текст вместо числа, выведите:

Номер этажа должен быть целым числом
УведомлениеОтвет 
try:
    floor = int(input("Номер этажа: "))
    print("Выбран этаж:", floor)

except ValueError:
    print("Номер этажа должен быть целым числом")

Задание 2. Расход топлива

Сложность: начальная

Даны:

fuel = 35
distance = 0

Вычислите расход топлива на 100 километров:

fuel / distance * 100

Обработайте ситуацию, когда расстояние равно нулю.

УведомлениеОтвет 
fuel = 35
distance = 0

try:
    consumption = fuel / distance * 100
    print("Расход:", consumption)

except ZeroDivisionError:
    print("Расстояние не может быть нулевым")

Задание 3. Выбор дня недели

Сложность: начальная

Дан список:

days = [
    "Понедельник",
    "Вторник",
    "Среда",
    "Четверг",
    "Пятница"
]

Пользователь вводит индекс.

Выведите соответствующий день.

Обработайте:

  • ValueError, если введено не число;
  • IndexError, если индекс выходит за пределы списка.

Отрицательные индексы в этой задаче также считайте недопустимыми.

УведомлениеОтвет 
days = [
    "Понедельник",
    "Вторник",
    "Среда",
    "Четверг",
    "Пятница"
]

try:
    index = int(input("Индекс дня: "))

    if index < 0:
        raise IndexError("Отрицательный индекс")

    print(days[index])

except ValueError:
    print("Введите целое число")

except IndexError:
    print("Такого дня в списке нет")

Задание 4. Получение настроек

Сложность: средняя

Дан словарь:

settings = {
    "theme": "dark",
    "language": "ru",
    "autosave": True
}

Пользователь вводит название настройки.

Получите значение через квадратные скобки.

Если ключ отсутствует, обработайте KeyError.

УведомлениеОтвет 
settings = {
    "theme": "dark",
    "language": "ru",
    "autosave": True
}

key = input("Название настройки: ")

try:
    print("Значение:", settings[key])

except KeyError:
    print("Настройка не найдена")

Задание 5. Проверка уровня заряда

Сложность: средняя

Пользователь вводит уровень заряда аккумулятора в процентах.

Допустимые значения — от 0 до 100.

Используйте raise ValueError, если число выходит за пределы диапазона.

Обработайте исключение и выведите понятное сообщение.

УведомлениеОтвет 
try:
    battery = int(input("Заряд аккумулятора: "))

    if battery < 0 or battery > 100:
        raise ValueError("Заряд должен быть от 0 до 100")

except ValueError as error:
    print("Ошибка:", error)

else:
    print("Заряд:", battery, "%")

Задание 6. Стоимость доставки

Сложность: средняя

Программа получает:

  • вес посылки;
  • стоимость доставки одного килограмма.

Оба значения вводятся пользователем.

Нужно:

  1. Преобразовать их в float.
  2. Проверить, что вес больше нуля.
  3. Проверить, что тариф неотрицательный.
  4. Вычислить стоимость.
  5. Обработать ValueError.

Задание 7. Распределение мест

Сложность: повышенная

В конференц-зале нужно распределить участников по столам.

Пользователь вводит:

  • количество участников;
  • количество столов.

Программа должна вычислить, сколько участников приходится на один стол при равномерном распределении без учёта остатка.

Требования:

  1. Обработать некорректный числовой ввод.
  2. Запретить отрицательное количество участников.
  3. Запретить нулевое или отрицательное количество столов.
  4. Использовать raise для проверки недопустимых значений.
  5. Использовать else для вывода результата.
  6. В finally сообщить о завершении проверки.
УведомлениеОтвет 
try:
    participants = int(input("Количество участников: "))

Задание 8. Мини-проект: терминал покупки билетов

Сложность: повышенная

Разработайте небольшую программу покупки билетов.

Исходные данные:

tickets = {
    "standard": 1200,
    "premium": 2500,
    "vip": 5000
}

available = 20

Пользователь вводит категорию билета и количество.

Программа должна:

  1. Проверить, существует ли категория.
  2. Преобразовать количество в целое число.
  3. Запретить нулевое и отрицательное количество.
  4. Проверить наличие нужного количества билетов.
  5. Рассчитать стоимость.
  6. Уменьшить остаток только после успешной проверки.
  7. Обработать ожидаемые исключения.
  8. Вывести результат покупки или понятное сообщение об ошибке.
УведомлениеОтвет 
tickets = {
    "standard": 1200,
    "premium": 2500,
    "vip": 5000
}

available = 20

try:
    category = input("Категория билета: ").lower()
    quantity = int(input("Количество билетов: "))

    if category not in tickets:
        raise ValueError("Неизвестная категория билета")

    if quantity <= 0:
        raise ValueError("Количество должно быть положительным")

    if quantity > available:
        raise ValueError("Недостаточно билетов")

    total = tickets[category] * quantity

except ValueError as error:
    print("Покупка отклонена:", error)

else:
    available -= quantity

    print("Покупка выполнена")
    print("Категория:", category)
    print("Количество:", quantity)
    print("Стоимость:", total)
    print("Осталось билетов:", available)

Обработка ошибок Python: краткое резюме

Обработка ошибок в Python позволяет управлять исключениями, возникающими во время выполнения программы. Конструкция try/except используется для перехвата ожидаемых исключений, например ValueError, ZeroDivisionError, KeyError и IndexError.

Блок else выполняется при успешном завершении try, а finally позволяет выполнить завершающие действия независимо от результата. Оператор raise используется для явного создания исключений, в том числе при проверке пользовательских данных.

Правильная обработка исключений помогает создавать более устойчивые программы, но не заменяет проверку логики и исправление ошибок в коде.
