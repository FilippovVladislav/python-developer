# STYLE GUIDE

Версия: 1.0

Этот документ определяет единый стиль оформления книги «Путь Python-разработчика».

---

# 1. Заголовки

Используем только три уровня.

# Глава

## Раздел

### Подраздел

Более глубокие уровни не использовать без необходимости.

---

# 2. Код

Для всех примеров используем подсветку синтаксиса.

```python
print("Привет, мир!")
```

Всегда указываем язык.

---

# 3. Названия переменных

Используем понятные английские имена.

Хорошо:

```python
monthly_income = 5000
user_name = "Vlad"
```

Плохо:

```python
a = 5
b = 10
```

Исключение — когда пример посвящён исключительно арифметике или синтаксису.

---

# 4. Иллюстрации

Каждая глава хранит свои изображения в собственной папке.

Пример:

chapter01/images/memory.png

Не использовать названия:

image1.png

photo.png

---

# 5. Стиль текста

• Короткие абзацы.
• Один абзац — одна мысль.
• Минимум воды.
• Сначала объяснение простыми словами.
• Затем теория.
• Затем пример.
• Затем практика.

---

# 6. Практика

Каждый новый раздел должен содержать практическое задание.

---

# 7. Код книги

Каждый пример должен запускаться без ошибок.

Не публиковать непроверенный код.

---

# 8. Термины

Используем единые названия.

Правильно:

- интерпретатор Python
- терминал
- редактор кода
- проект
- репозиторий

Не использовать разговорные сокращения вроде «питон» в основном тексте книги.

---

# 9. Версии

Каждая глава имеет номер версии.

Например:

v0.1 — черновик

v0.5 — после редактуры

v1.0 — финальная версия
