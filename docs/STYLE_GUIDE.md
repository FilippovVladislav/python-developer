# STYLE GUIDE

Версия: 2.0

Этот документ определяет единый стиль оформления книги «Путь Python-разработчика».

---

# Заголовки

Используем только три уровня.

# Глава

## Раздел

### Подраздел

Более глубокие уровни использовать только при крайней необходимости.

---

# Стиль текста

Главное правило:

Одна мысль — один абзац.

Использовать:

- короткие предложения;
- минимум воды;
- простой язык;
- объяснение от простого к сложному.

Каждый раздел должен отвечать на вопрос читателя.

---

# Код

Все примеры должны:

- запускаться без ошибок;
- быть короткими;
- соответствовать PEP 8;
- использовать английские имена переменных.

Пример:

```python
monthly_income = 5000
user_name = "Vlad"
```

Не использовать:

```python
a = 5
b = 10
```

---

# Иллюстрации

Каждая глава хранит изображения отдельно.

Пример:

book/images/chapter01/

Использовать понятные названия файлов.

Хорошо:

memory-layout.svg

Плохо:

image1.png

---

# Quarto

Использовать только стандартные возможности Quarto.

Предпочитать:

- callout-note
- callout-tip
- callout-warning
- callout-important

Не использовать HTML без необходимости.

---

# Практика

Каждый раздел должен содержать минимум одно практическое задание.

Каждая глава должна завершаться выводами.

---

# Термины

Использовать единые названия.

Правильно:

- интерпретатор Python
- терминал
- редактор кода
- проект
- репозиторий

Не использовать разговорные сокращения.
