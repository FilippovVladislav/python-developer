# BOOK PHILOSOPHY

Эта книга создаётся не для изучения синтаксиса Python.

Она создаётся для формирования мышления разработчика.

---

Главные принципы проекта:

- понимать, а не запоминать;
- объяснять "почему", а не только "как";
- учиться через практику;
- двигаться постепенно;
- каждый новый раздел делает читателя сильнее.

---

Мы не стремимся написать самую большую книгу.

Мы стремимся написать книгу, которую действительно захочется дочитать до конца.

---

Главная цель проекта — помочь человеку получить первую работу Python-разработчиком.
