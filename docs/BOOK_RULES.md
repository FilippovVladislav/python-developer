# BOOK RULES

Документ определяет обязательные требования ко всем главам книги.

---

# Структура главы

Каждая глава должна содержать:

1. Введение
2. Теорию
3. Пример
4. Практику
5. Типичные ошибки
6. Главное запомнить
7. Домашнее задание (если необходимо)

---

# Практика

Каждая глава должна содержать минимум:

- одно простое упражнение;
- одну задачу;
- один мини-проект (если тема позволяет).

---

# Код

Каждый пример обязан:

- запускаться;
- быть проверенным;
- соответствовать PEP 8.

---

# Качество

Глава считается завершённой, если:

- текст вычитан;
- код проверен;
- HTML собирается;
- PDF собирается;
- нет известных ошибок.
