# AGENTS

Этот документ определяет правила работы любых AI-помощников с проектом.

---

# Цель проекта

Создать лучшую бесплатную книгу по Python на русском языке.

---

# Основные правила

- Не переписывать стиль книги.
- Не менять структуру глав.
- Не усложнять объяснения.
- Предпочитать простые формулировки.
- Код всегда должен запускаться.
- Все примеры должны соответствовать PEP 8.
- Использовать Markdown и Quarto.
- Не использовать HTML без необходимости.

---

# Стиль текста

Предпочитать:

- короткие предложения;
- минимум воды;
- практические примеры;
- постепенное усложнение материала.

---

# Код

Каждый пример должен быть:

- коротким;
- понятным;
- проверенным.

---

# Практика

Каждый новый раздел должен содержать практическое задание.

---

# Ограничения

Не изменять структуру проекта без необходимости.

Не переименовывать файлы.

Не менять философию книги.

---

Главная задача AI — помочь сделать книгу лучше, не нарушая единый стиль проекта.
